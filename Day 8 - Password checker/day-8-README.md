# 🔑 Day 8 - Password Checker

> Part of the [100 Days of JavaScript](../README.md) challenge.

## 📌 What I Built

A password checker that asks the user to set a password, then keeps prompting until the correct password is entered before granting access.

## 🧠 Concepts Covered

- `prompt()` for collecting user input
- `while` loop to repeat until the password matches
- Strict equality (`===`) and inequality (`!==`) comparisons
- `if / else` for success and failure feedback

## 📤 Output

```
===== PASSWORD CHECKER =====
Password = mySecret123
❌ Wrong Password
Try Again...

❌ Wrong Password
Try Again...

✅ Login Successful
Welcome to the system!
```

## ▶️ How to Run

Open `day-8.html` in a browser → **Inspect** → **Console** → follow the prompts.
