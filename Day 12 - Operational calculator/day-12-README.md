# 🧮 Day 12 - Operational Calculator

Built a calculator to practice **first-class functions** — operation functions (`add`, `subtract`, `multiply`, `divide`) are stored in variables and passed as arguments to a generic `calculator()` function, dispatched via a `switch` statement.

## 💡 Concepts Practiced
- First-class functions (functions stored in variables & passed as arguments)
- `switch` statement for operation dispatch
- `prompt()` & `Number()` for user input

## 🚀 How to Run
1. Open `day-12.html` in a browser.
2. Follow the `prompt()` dialogs to pick an operation and enter two numbers.
3. Open **Console** (`F12`) to see the result.
