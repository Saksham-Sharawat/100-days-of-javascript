# Day 3: Operators

Code for Day 3 of the 100 Days of JavaScript challenge.

## Topics Covered
- Arithmetic Operators (`+`, `-`, `*`, `/`, `%`, `**`)
- Unary Operators (`++`, `--`)
- Assignment Operators (`=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`)
- Comparison Operators (`==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`)
- Logical Operators (`&&`, `||`, `!`)

## How to Run
Open `day-3.html` in a browser and check the Developer Tools Console (F12) for the output.
