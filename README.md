# 🚀 100 Days of JavaScript Challenge

Welcome to my **100 Days of JavaScript** repository! 

## 🎯 Purpose of this Repository

The purpose of this repository is to document my journey through the "100 Days of Code" challenge, dedicated entirely to mastering **JavaScript**. 

By committing to coding every single day for 100 days, my goals are to:
- Build a strong foundational understanding of JavaScript.
- Understand the quirks, features, and core mechanics of the language (from variables and data types to asynchronous programming and DOM manipulation).
- Cultivate a habit of consistent daily coding and continuous learning.
- Build a portfolio of small projects and scripts that demonstrate my progress.

This repository serves as my public journal, codebase, and accountability partner.

## 📂 Repository Structure

Each day's progress is organized into its own dedicated folder. Inside each folder, you will generally find:
- An HTML file (`day-x.html`) to serve the content.
- A CSS file for styling.
- A JS file containing the JavaScript logic and concepts learned for that specific day.

## 💻 How to Run the Code

Since this challenge primarily involves vanilla JavaScript running in the browser:
1. Clone this repository to your local machine.
2. Navigate to the folder of the specific day you want to check (e.g., `Day 1 - Variables`).
3. Open the HTML file (e.g., `day-1.html`) in any modern web browser.
4. Right-click on the page, select **Inspect**, and navigate to the **Console** tab to see the JavaScript output.
