# 🧾 Day 11 - Bill Calculator

> Part of the [100 Days of JavaScript](../README.md) challenge.

## 📌 What I Built

A bill calculator that sums item prices and applies tax using **rest** and **default parameters**.

## 🧠 Concepts Covered

- **Rest Parameters** (`...prices`) — accept any number of arguments
- **Default Parameters** (`tax = 18`) — fallback value when none is passed

## ▶️ How to Run

Open `day-11.html` in a browser → **Inspect** → **Console**.
