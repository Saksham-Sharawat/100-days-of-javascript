# 📅 Day 2 — Primitive Data Types

> **100 Days of JavaScript Challenge**
> 🗓️ Topic: JavaScript's 7 Primitive Data Types & the `typeof` Operator

---

## 🎯 Learning Objective
Understand the 7 primitive data types in JavaScript and how to check them using `typeof`.

## 📚 Concepts Covered
### The 7 Primitive Data Types
1. **`string`**: Text (`"Saksham"`).
2. **`number`**: Integers and floats (`19`).
3. **`boolean`**: `true` or `false`.
4. **`undefined`**: Declared but not assigned.
5. **`null`**: Intentional absence of value.
6. **`bigint`**: Arbitrarily large numbers.
7. **`symbol`**: Unique identifier.

### The `typeof` Operator
Returns a string describing the type of a value.
*(Note: `typeof null` returns `"object"` due to a historical bug).*

## 📁 File Structure
- `day-2.html`: Renders the page.
- `day-2.css`: Styles the page.
- `day-2.js`: Examples of all 7 primitive data types with `typeof` checks.

## 🚀 How to Run
1. Open `day-2.html` in a browser.
2. Press `F12` to view the Console.

## 💡 Key Takeaways
- Primitives are immutable.
- `typeof` checks value types at runtime.
- `null` is not an object.
