# 🔐 Day 6 - Authorization System

> Part of the [100 Days of JavaScript](../README.md) challenge.

## 📌 What I Built

A simple login authorization system that checks user credentials and displays a welcome message using JavaScript operators.

## 🧠 Concepts Covered

| Operator | Symbol | Usage |
|----------|--------|-------|
| Ternary | `? :` | Login success/failure check |
| Logical AND | `&&` | Both username & password must match |
| Nullish Coalescing | `??` | Fallback name if `null`/`undefined` |


## 📤 Output

```
Username : Saksham
Password : 123456789
Login successful✅
Welcome, Saksham
```

## ▶️ How to Run

Open `day-6.html` in a browser → **Inspect** → **Console**.
