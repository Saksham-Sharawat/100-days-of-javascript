# 🎯 Day 9 - Number Guessing Game

> Part of the [100 Days of JavaScript](../README.md) challenge.

## 📌 What I Built

An interactive number guessing game where the player tries to guess a secret number between 1 and 10. After each guess, the game gives a hint — **Too low** or **Too high** — and keeps looping until the correct number is found.

## 🧠 Concepts Covered

- `do...while` loop for repeating until a condition is met
- `prompt()` & `Number()` for user input
- `if / else if / else` for feedback branching
- Input validation (checking range 1–10)

## 🎮 How It Works

1. A secret number (`7`) is set.
2. The player is prompted to guess a number between **1 and 10**.
3. If the guess is out of range, a warning is shown.
4. If the guess is too low → `"Too low"`, too high → `"Too high"`.
5. The loop continues until the player guesses correctly.
6. A congratulations message is displayed on success 🎉

## ▶️ How to Run

Open `day-9.html` in a browser → **Inspect** → **Console** → follow the prompts.
