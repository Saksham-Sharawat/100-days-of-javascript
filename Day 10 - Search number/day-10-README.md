# 🔍 Day 10 - Search Number

> Part of the [100 Days of JavaScript](../README.md) challenge.

## 📌 What I Built

Searches for a user-inputted number inside a **3×3 matrix** and returns its **row & column** position.

## 🧠 Concepts Covered

- Nested `for` loops over a 2D array
- Labeled `break` (`break search`) to exit both loops at once
- Boolean flag to track if a match was found

## ▶️ How to Run

Open `day-10.html` in a browser → **Inspect** → **Console** → enter a number when prompted.
