# 🏦 Day 7 - Bank System

> Part of the [100 Days of JavaScript](../README.md) challenge.

## 📌 What I Built

An interactive bank system where users log in with a username & PIN, then choose to check balance, deposit, or withdraw.

## 🧠 Concepts Covered

- `prompt()` & `Number()` for user input
- `if / else if / else` for menu branching
- Arithmetic operators for balance calculations

## ▶️ How to Run

Open `day-7.html` in a browser → **Inspect** → **Console** → follow the prompts.
