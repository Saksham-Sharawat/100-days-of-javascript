# 📅 Day 1 — Variables

> **100 Days of JavaScript Challenge**
> 🗓️ Topic: Introduction to JavaScript Variables

---

## 🎯 Objective
Learn to declare variables using `let`, `const`, and `var` and output them to the console.

## 📚 Concepts Used
1. **`let`**: Block-scoped variable declaration that allows reassignment.
2. **`const`**: Block-scoped variable declaration for values that won't change.
3. **`var`**: Function-scoped (legacy) variable declaration.
4. **`console.log()`**: Output values to the console.

## 💡 What I Learned
- `let` and `const` are the preferred modern ways to declare variables in JavaScript.
- `var` is an older way to declare variables and is mostly avoided in modern JS due to scoping differences.
- `console.log()` is essential for debugging and viewing output.
